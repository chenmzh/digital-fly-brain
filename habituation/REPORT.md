# 果蝇连接组模型中的习惯化样响应

## 短时突触抑制、状态干预与响应预测

[完整报告 PDF](report.pdf) · [源码与构建说明](synthesis/README.md) · [修订说明](synthesis/EDITORIAL_PLAN.md)

### 研究目的与方法

重复刺激后的响应减弱及休息后的恢复，是习惯化的基本特征。本研究采用固定果蝇连接组上的全脑泄漏积分发放模型，以70个JO-CE机械感觉神经元为输入，记录aBN1及相关下行神经元的脉冲计数。比较原固定连接模型M0与局部短时突触抑制模型M1，再通过状态干预、低维预测和特征补测，考察响应历史的来源及适用范围。

M1在4,764条JO-CE兴奋性输出边加入可恢复资源变量，消耗比例U=0.01、恢复时间常数2秒。全脑结构及生理参数保持不变。三个阶段共1006个正式观测窗口，其中6个为空白检查；所用11个种子标识均属于同一图谱上的输入实现，不代表动物个体。

### 重复刺激与状态干预

M0在两种刺激间隔下均无跨次计数递减。M1在0.5秒间隔下的平均递减比例为90.22%，2秒间隔下为9.88%。短间隔训练后的10秒探测均值恢复到初次水平，但逐实现的恢复比例仍有差异。M1初次响应为8.2脉冲，较M0的9.8下降约16.3%；下行神经元的初始计数较低，限制了相对效应量的解释。

训练末态干预中，aBN1均值由初次8.2降至0.4脉冲。仅重置膜电位等快状态后仍为0.4，恢复资源后为8.2；同时恢复两类状态后，五例全脑事件均与初次一致。直接驱动aBN1时，训练前后的事件也一致。这些结果支持M1内部的资源状态解释，并表明相关下游通路仍可被直接驱动；实验未涉及真实运动或肌肉疲劳。

### 低维预测

资源模型S和积累模型I分别估计两个读出系数，仅使用旧M1短间隔的60个训练窗口；另80个已见窗口用于回顾性检查。两者都能近似旧曲线。

随后在新全脑输出产生前保存102个窗口的预测，再运行三个新条件。S在全部三个条件达到MAE≤1.5脉冲，I仅在原刺激形状的新种子对照中达到。总体RMSE分别为1.036和3.019脉冲。S采用与M1相近的资源方程，其优势包含这一先验的贡献。

三个强刺激实现均出现局部响应回升，两种代理未能准确再现。该现象在观察结果后追加分析，未用于选择条件或重新拟合。其时序与回路来源尚未通过干预确定。

### 经典特征补测

| 特征 | 结果 |
|---|---|
| H1、H2、H4(a) | 所测条件下出现递减、自发恢复及较高重复频率引起的更强递减 |
| H3 | 2秒部分恢复下3/3符合补充增强判据；10秒条件0/3符合原判据，可由残余状态解释 |
| H4(b) | 24次补测后三例满足比较条件，但F50均未分辨出频率差异；按初次80%评价仅1/3高频明确更早，未获得一致支持 |
| H5 | 150/200Hz的平均D为98.0%/83.3%；方向3/3一致，2/3达到预设差值 |
| H6 | 12次与24次训练后的五点恢复计数逐实现相同，未观察到追加训练效应 |
| H7 | 两个B的aBN1基线均为零，未能判断刺激特异性 |
| H8 | 两个B激活非输入神经元，但后续A响应未超过等时休息对照 |
| H9、H10 | 分别因缺少可靠解除效应及未实施长期协议，未完成检验 |

H4(b)的一次补测是在看到原比较条件不足后设计的，保留了原阈值。H5的强度变量为人工神经输入率，尚未标定到机械刺激强度。

### 解释与局限

局部资源耗竭与恢复能够解释本模型中的部分习惯化样响应，资源动力学的低维近似也可预测部分新条件下的计数。但输出曲线的拟合并不能唯一识别内部机制；局部回升还表明，平均资源与简单读出未描述全部动力学。

当前缺少活体数据、可比较的B基线、局部图和匹配随机图对照。因此，真实果蝇是否采用相同机制，以及完整连接结构对预测的额外贡献，仍需独立实验。后续可在固定平均输入率和初态下改变时序、同步性或细胞分配，并比较不同模型对留出刺激和细胞干预的预测。
