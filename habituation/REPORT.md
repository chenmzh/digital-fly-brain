## 核心问题：正常传递如何成为历史依赖？

### Q1：原有连接结构是否已经足够？

同一完整图谱上的固定连接模型M0，在本次JO-CE重复刺激的两个间隔下均没有跨次计数递减。仅在4,764条兴奋性输出边加入可恢复资源的M1，在0.5秒间隔下产生平均90.22%的早晚期递减与休息恢复；2秒间隔的递减仅9.88%。

这说明局部慢状态在当前条件下足够，不证明它是唯一机制。M1的初次响应也从M0的9.8降至8.2，下游存在低计数地板，不能隐藏正常功能代价。

### Q2：历史储存在哪里，输出是否已经失能？

从同一训练末态独立干预：初次aBN1均值8.2，训练后0.4；清快状态仍0.4，恢复资源后8.2。双重恢复与初次全脑事件相同；训练前后直接驱动aBN1的全脑事件也一致。

这些结果支持已构造M1内部的资源状态归因，并表明相关神经通路仍可被强驱动。不等于排除所有真实身体疲劳，也不把人工资源恢复称为自然去习惯化。

### Q3：需要整个全脑模型才能预测输出吗？

两个各含两项拟合系数的代理都能接近旧曲线，因此输出层面的拟合不能唯一识别内部机制。随后先冻结102个新窗口的预测，再按代理分歧设计新协议并运行全脑检验。

资源代理S在3/3协议达到MAE≤1.5脉冲，积累代理I仅1/3；总体前瞻RMSE分别1.036、3.019。资源代理具有与M1一致的机制先验，这不是无先验的生物机制裁决。

三个强刺激实现的局部反弹是事后探索性发现：平均误差达标可以与细节预测失败并存。它既不证明完整连接组无用，也不证明只有真实全图才有必要。

### Q4：它符合哪些经典习惯化特征？

| 特征 | 综合后的最新状态 |
|---|---|
| H1、H2、H4(a) | 支持相应条件下的递减、自发恢复和更频繁刺激引起更强递减 |
| H3 | 2秒部分恢复下3/3支持补充增强筛查；10秒条件未达原较严格门槛，残余状态足以解释 |
| H4(b) | 资格补测后3/3具条件，但F50均未分辨；首次80%仅1/3高频明确更早，尚未稳健建立 |
| H5 | 弱/强人工输入率的D均值98.0%/83.3%；方向3/3一致，2/3达到预设效应量 |
| H6 | 12→24次训练后三例的五点恢复计数均不变，本协议未观察到效应 |
| H7 | 两个B的aBN1基线不足，无法判定，不是阴性 |
| H8 | 两个B确实激活网络，但均未使A恢复超过等时休息，本协议未观察到解除增益 |
| H9、H10 | 分别缺少可靠解除前提及长期检验，未完成测试 |

“未观察到”“未分辨”“资格不足”和“未测”分开报告；这些筛查不是全部数学或生物版本的统一定义。

### Q5：真正还缺什么？

- 与真实刺激、时间尺度、神经和行为读出匹配的生物数据。
- 可比较的B基线、可靠的解除刺激，以及对敏化和残留输出的控制。
- 对时序、细胞分配和干预后果的预先冻结预测，检验局部反弹来源。
- 相同数据预算下的机制、局部图、匹配随机图和全图对照，证明连接结构新增了什么预测信息。

这些是尚未执行的后续工作，不把已经完成的旁路、代理和恢复补测重复列为“未来实验”。

## 数量与透明性

三个阶段合计 **1006个正式观测窗口、此前已审计的1212个事件文件**。其中6个窗口为空白检查；60个拟合和80个回顾性窗口包含在首轮280窗口内，不再次增加总数。共有11个不同种子标识，均来自一个连接组，**不是11只动物**，也不意味着1006个独立样本。

本文统一使用Q1–Q5表示研究问题、H1–H10表示经典特征，消除旧阶段二假设编号与hallmark编号冲突。前瞻、回顾性、事后探索和结果驱动的资格补测分别标明。三份历史报告不覆盖；原始事件仍仅本地保存，GitHub提供代码、汇总及报告。
